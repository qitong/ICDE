# ICDE MVP 设计文档

> Integrated Clinical-Data Environment：临床研究的"IDE"

## 1. 产品定位

### 1.1 一句话描述
用自然语言完成临床数据分析，输出可发表的图表和论文草稿。

### 1.2 核心价值
**"一个人完成研究"**——整合数据筛选、统计分析、可视化、论文写作等碎片化操作，让PI无需编程即可端到端完成临床研究。

### 1.3 目标用户
- 主要：临床医生/PI（非技术背景）
- 次要：生物统计师/数据科学家（有编程能力）

### 1.4 MVP范围
| 维度 | 范围 |
|------|------|
| 数据 | 肺癌领域公开/模拟数据 |
| 功能 | 自然语言筛选 → 统计分析 → 论文级输出 |
| 部署 | 云端，无需登录 |
| 暂不包含 | 数据清洗、EDC、多中心协作 |

## 2. 核心流程

```
┌─────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────┐
│ 选择数据 │ →  │ 自然语言描述 │ →  │ 分析集预览   │ →  │ 模型推荐 │
└─────────┘    │   研究意图   │    │  可迭代调整  │    │ 解释+备选│
               └─────────────┘    └─────────────┘    └─────────┘
                                                           │
                                                           ▼
┌─────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────┐
│  导出   │ ←  │ Canvas编辑  │ ←  │  生成输出   │ ←  │ 执行分析 │
│Word/PDF │    │  图表/文字  │    │ 表格/图/文字 │    │         │
└─────────┘    └─────────────┘    └─────────────┘    └─────────┘
```

### 2.1 用户旅程示例

1. 打开应用，选择"肺癌示例数据集"
2. 输入："研究ALK阳性患者二线治疗后的生存情况"
3. 系统输出**分析集预览**：
   - 入选：ALK融合阳性，N=120
   - 排除：无二线治疗记录(N=45)，随访不足(N=12)
   - 可展开查看筛败明细
4. PI调整："把随访时间放宽到3个月以上"
5. 系统更新分析集，PI确认
6. 系统推荐分析方案：
   > **推荐：Kaplan-Meier + Log-rank检验**
   > 原因：比较ALK阳性vs阴性的生存曲线，无需调整协变量
   >
   > 备选：Cox回归（如需调整年龄、PS评分等）
7. PI确认，系统执行分析
8. 输出：生存曲线图 + 统计表 + Results段落
9. PI在Canvas中微调图表标题
10. 导出Word文档

│  ├─ 分析集│ │                                     │ │  │ 用户输入   │  │
│  ├─ 脚本│  │                                     │ │  │           │  │
│  └─ 输出│  │      (Canvas / 预览区)               │ │  │ 系统回复   │  │

### 3.2 各区域职责

| 区域 | 功能 |
|------|------|
| 左栏-文件导航 | 数据集、分析集、脚本、输出产物；可折叠 |
| 中栏-主工作区 | Tab切换（图表/表格/文字/代码）；Canvas编辑 |
| 右栏-对话 | 自然语言交互；分析控制入口 |

## 4. 技术架构

### 4.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                     前端 (React + Tailwind)                  │
└─────────────────────────────────────────────────────────────┘
                              │ REST API
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   后端 (Python / FastAPI)                    │
│                                                             │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │ 对话 & 状态  │  │ LLM 调用     │  │ 代码执行     │         │
│  │ (内存/文件)  │  │ (国内大模型) │  │ (本地Python) │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
│                                                             │
│  ┌─────────────┐  ┌─────────────┐                          │
│  │ 数据查询     │  │ 文件 & 导出  │                          │
│  │ (SQLite)    │  │ (本地文件)   │                          │
│  └─────────────┘  └─────────────┘                          │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 技术选型

| 模块 | 选型 | 说明 |
|------|------|------|
| 前端 | React + Tailwind | 标准选型 |
| 后端 | FastAPI | 单体服务，简单直接 |
| LLM | DeepSeek / Qwen | 国内可直接调用，代码能力强 |
| Embedding | BGE-M3 / 智谱 | 本地或API |
| 数据存储 | SQLite + 本地文件 | MVP够用 |
| 代码执行 | 本地Python进程 | MVP阶段暂不用沙箱 |
| 导出 | python-docx + matplotlib | Word和图表生成 |

## 5. 数据模型

### 5.1 事件驱动的Problem List

患者数据统一转换为事件时间线结构，支持自然语言语义筛选。

```yaml
patient_id: P001
baseline:
  age: 58
  gender: M
  smoking: 30 pack-years
  ps_score: 1

events:
  - date: 2023-01-15
    type: DIAGNOSIS
    detail: "非小细胞肺癌，右肺上叶，腺癌，cT2N2M0 IIIA期"

  - date: 2023-01-20
    type: MOLECULAR
    detail: "ALK融合阳性(FISH), EGFR野生型, PD-L1 40%"

  - date: 2023-02-01
    type: TREATMENT_START
    detail: "培美曲塞+卡铂，一线治疗"
    line: 1

  - date: 2023-08-15
    type: PROGRESSION
    detail: "肺内病灶增大，新发肝转移"

  - date: 2023-08-20
    type: TREATMENT_START
    detail: "克唑替尼，二线治疗"
    line: 2

  - date: 2023-09-30
    type: ADVERSE_EVENT
    detail: "视觉障碍 Grade 2"
    grade: 2
```

### 5.2 事件类型

| 事件类型 | 说明 | 关键属性 |
|----------|------|----------|
| DIAGNOSIS | 初诊/新发诊断 | 病理、分期 |
| MOLECULAR | 分子检测 | 基因、表达 |
| TREATMENT_START | 开始治疗 | 方案、线数 |
| TREATMENT_END | 结束治疗 | 原因 |
| RESPONSE | 疗效评估 | CR/PR/SD/PD |
| PROGRESSION | 进展 | 部位 |
| ADVERSE_EVENT | 不良事件 | 类型、等级 |
| SURGERY | 手术 | 术式 |
| RADIOTHERAPY | 放疗 | 部位、剂量 |
| DEATH | 死亡 | 原因 |

## 6. 语义筛选实现

### 6.1 两阶段方案

```
┌─────────────────────────────────────────────────────────────┐
│                    预处理（离线）                            │
│  患者原始数据 → LLM提取事件 → Problem List → Embedding      │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    查询（在线）                              │
│                                                             │
│  ① "二线后用ALK靶向药的患者"                                 │
│                    ↓                                        │
│  ② Embedding相似度召回 → Top 20% 候选                        │
│                    ↓                                        │
│  ③ LLM批量精筛（每批50-100条）                               │
│                    ↓                                        │
│  ④ 最终结果集                                               │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 筛选示例

| 用户输入 | 匹配逻辑 |
|----------|----------|
| "ALK阳性的患者" | MOLECULAR事件含"ALK融合阳性" |
| "二线后进展的患者" | TREATMENT_START(line=2)之后有PROGRESSION |
| "克唑替尼后脑转移" | TREATMENT含"克唑替尼" → 之后PROGRESSION含"脑转移" |
| "因不良反应停药" | TREATMENT_END.reason含"毒性" |

## 7. LLM编排

### 7.1 System Prompt结构

```
你是ICDE的分析助手，帮助临床研究者完成数据分析。

【当前状态】
- 数据集: {dataset_name}
- 分析集: {cohort_summary}
- 已选变量: {selected_features}
- 分析阶段: {current_stage}

【你的职责】
1. 理解研究意图，生成合理的入排标准
2. 推荐统计方法并解释原因
3. 生成可执行的Python代码
4. 输出论文级的图表和文字

【输出格式】
返回结构化JSON：
- cohort_update: 分析集变更
- model_recommendation: 模型推荐
- code: 待执行代码
- narrative: 论文文字
- chart_config: 图表配置
```

### 7.2 意图分支

| 意图 | 处理 |
|------|------|
| 研究定义 | 生成分析集 |
| 调整筛选 | 更新入排条件 |
| 选择模型 | 推荐+备选+解释 |
| 执行分析 | 生成代码并运行 |
| 修改输出 | 调整图表/文字配置 |

## 8. 输出规格

### 8.1 统计表格

**Table 1（基线特征）**：
- 连续变量：均值±SD 或 中位数(IQR)
- 分类变量：n(%)
- 组间比较P值

**分析结果表**：
- 回归系数/HR/OR
- 95% CI
- P值（自动标注显著性）

### 8.2 图表

| 类型 | 用途 |
|------|------|
| Kaplan-Meier | 生存分析 |
| Forest plot | 亚组分析 |
| 瀑布图 | 疗效展示 |
| 桑基图 | 治疗流程 |

Canvas可编辑：标题、轴标签、颜色、字体、图例位置

### 8.3 论文文字

**Methods模板**：
```
本研究回顾性纳入了[数据来源]中[时间范围]的[疾病]患者。
入选标准：[入选条件]。排除标准：[排除条件]。
最终纳入[N]例患者进行分析。
```

**Results**：LLM根据统计结果自动生成描述性段落
